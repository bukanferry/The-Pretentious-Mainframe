# Hexadella / The Pretentious Mainframe

> *Because the internet didn't have enough useless monuments to digital vanity.*

Welcome to the underlying architecture of absolutely nothing important. This repository contains the source code for a highly sophisticated, completely unnecessary simulation of a retro-terminal mainframe. 

It was built under the delusion that tracking CPU cycles and playing digital Russian Roulette makes a website "profound."

## Core Modules (If you can call them that)

- **The Monitor (`/monitor`)**
  A dashboard that tracks server vitals in real-time. It exists primarily to make the server feel important and to spit out pseudo-philosophical quotes about "digital existence." It's basically an ECG monitor for a machine that doesn't care if you're watching.
  
- **The Terminal (`/terminal`)**
  A purely cosmetic, client-side shell environment. It logs your fake keystrokes and warns you about "unauthorized access." It’s entirely secure because it doesn't actually connect to anything that matters. It's security theatre at its finest.

- **The Gamble (`/gamble`)**
  A digital Russian Roulette. Six chambers. One fatal exception. You pull the trigger, and if you die, you get a retro Blue Screen of Death. It's a mathematically cruel metaphor for the consequences of your own hubris. The house always wins.

## The Architecture of Overkill

- **Laravel**: Used to serve what could have been basic HTML files, because overkill is the entire point.
- **Tailwind CSS**: To ensure the digital apocalypse is fully responsive and looks elegantly vintage on your smartphone.
- **Vanilla JavaScript**: For the terminal mechanics and roulette logic, because importing a modern framework for this would be the *real* tragedy.
- **Chomsky Font**: So everything you read feels like a Victorian-era death threat.

## Installation

If, for some incomprehensible reason, you wish to host this tribute to technological sarcasm on your own machine:

```bash
git clone <repository-url>
cd hexadella-space
composer install
npm install
npm run build
cp .env.example .env
php artisan key:generate
php artisan serve
```
